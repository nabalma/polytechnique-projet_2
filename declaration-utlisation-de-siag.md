# Déclaration d’utilisation d’Intelligence Artificielle (IA)

Dans le cadre de ce projet scolaire, nous déclarons avoir utilisé un outil d’intelligence artificielle (Claude ) comme support au développement.

L’IA a été utilisée uniquement pour assister dans la compréhension,  le débogage du code et la reformulation de textes.  
Toutes les décisions finales, validations, logique métier, tests et intégrations ont été réalisées par les membres de l’équipe.

## 1. Outil utilisé

- Outil : Claude 

---

## 2. Endroits où l’IA a été utilisée

### 2.1 Aide à la programmation (TypeScript / Angular)
- Correction d’erreurs TypeScript
- Conseil pour la restructuration de composants Angular
- Propositions de fonctions utilitaires

### 2.2 HTML / CSS
- Amélioration de styles CSS
- Ajustement de design de cartes (cards)

### 2.3 Git / gestion de branches
- Commandes Git plutot complexes
- Explication des erreurs Git

### 2.4 Documentation / messages de commit
- Traduction et reformulation de messages de commit
- Aide à rédiger des descriptions plus claires

---

## 3. Limites de l’utilisation

- Aucune fonctionnalité n'a été généré en entier par l'IA( seulement des petites partie de code )
- Tous les tests ont été exécutés par les membres de l’équipe.
- Les choix d’architecture et de conception ont été faits par l’équipe.

---

## 4. Responsabilité académique

Nous confirmons que le travail final rendu est le résultat du travail de l’équipe, et que l’utilisation de l’IA a servi uniquement comme outil d’assistance.
